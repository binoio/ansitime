ANSITime

Native macOS standalone viewer and Finder Quick Look plugin for authentic BBS & ANSI art.

Download for macOS View on GitHub

Finder Quick Look

Highlight any .ans, .asc, or .diz file in Finder and tap the spacebar for instant, high-fidelity BBS preview.

Authentic CP437 Engine

Built with fTelnet's IBM PC Code Page 437 bitmap font engine and authentic VGA 16-color palette without running local Python HTTP servers.

SAUCE Metadata Inspector

Auto-detects SAUCE records: title, artist, group, date, and dimensions. Automatically formats screen height for tall art.

Export & Share

Export pixel-perfect rendered art directly to high-resolution PNG images, copy plain text, or share via macOS share sheets.
